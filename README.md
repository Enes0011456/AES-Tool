# AES-Tool
AES Tool

Aes_tool, Python tabanlı projelerinizde veya araç setlerinizde güvenli şifreleme ve veri koruma işlemlerini hızlı bir şekilde gerçekleştirebilmeniz için geliştirilmiş hafif bir modüldür.

🚀 Özellikler
Güçlü Şifreleme: Verilerinizi güvenli algoritmalarla şifreler ve çözer.

Modüler Yapı: ToolKit-Hub veya benzeri ana proje yapılarıyla kolayca entegre olabilir.

Kolay Kullanım: Sade fonksiyon yapıları sayesinde projelerinize minimum kod satırıyla dahil edilebilir.

📦 Kurulum
Projeyi klonladıktan sonra gerekli bağımlılıkları yükleyin:

Bash
git clone https://github.com/kullaniciadi/proje-adi.git
cd proje-adi
pip install -r requirements.txt
💻 Kullanım
Modülü projenize dahil etmek ve temel şifreleme işlemlerini gerçekleştirmek için örnek kullanım:

Sifreleme de neler yapabilir peki : 
AES-256-CBC/GCM + ChaCha20 + XOR

Sifreleme sıralaması nasıldır peki:
AES-256-CBC/GCM ---> ChaCha20 ---> XOR
